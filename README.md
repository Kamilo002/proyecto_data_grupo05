# proyecto_data_grupo05
# ANALISIS DE CONTENIDO DE RELACIONES EN REDES SOCIALES
En este proyecto se analiza como se figuran las relaciones interpersonales de pareja y sus temas como amor, celos, ruptura, independencia, deseo, etc. En los posts de las redes sociales.
# OBJETIVO 
La misión de este proyecto es identificar patrones notables en los contenidos de las redes sociales relacionados con las relaciones y que temas suelen ams predominar en este tipo de publicaciones.

# RECOLECCION DE LOS DATOS
Se hizo un dataset de 20 posts distintas clasificadas segun:
Tema: Celos, independencia, toxicidad
Tono: Positivo, negaitvo, neutro
Numero de interacciones: Likes
